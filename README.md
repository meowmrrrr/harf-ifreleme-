"Şifreli yazıyı çevirmek" adlı kısım önceden şifrelenmiş bir yazıyı normal harflere dönüştürerek okunulabilir bir hâle getirir.
"Normal yazıyı çevirmek" kısmı ise sizin yazdığınız şifresiz kelimeleri şifreleyerek ekrana yazar.
